# Sample Hardhat 3 Beta Project (minimal)

This project has a minimal setup of Hardhat 3 Beta, zkSync plugins were added in order to connect zkSYS Devnet network (zksolc).

## What's included?

The project includes native support for TypeScript, Hardhat scripts, tasks, and support for Solidity compilation and tests.

## REMEMBER:
This is a fork version of main proyect. Every change must be commited on own branch, created from **smartcontract** branch as definitive.
